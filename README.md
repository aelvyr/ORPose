# ORPose - manual labeling tool

This is a tool for manual labeling of 3D poses in videos.
This tool was created to aide in the correction of 3D pose labels, generated by the ORPose tool.
It provides a user-friendly interface for correcting and refining the labels.

## Installation

First you will need to install the required dependencies. You can do this by running the following command:

```
pip install -r requirements.txt
```

Afterwards, you will need to put your pose data in to the `output_3d/<dataset_name>` directory with the name `hand_poses_2d.npz`.
And the video data in the `inputs/<dataset_name>` directory with the name `<camera_name>_synced_cut.MP4`.

Then you can run the tool by executing the following command:

```
python3 src/main.py <dataset_name>
```
